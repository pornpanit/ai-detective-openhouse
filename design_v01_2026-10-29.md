**Status**: Approved design, pre-development

## 1. Overview

| Item | Value |
|---|---|
| Purpose | Game-based experiment measuring human ability to distinguish AI-generated faces from real faces across human generations |
| Setting | University openhouse; participants join by scanning a QR code on personal phones |
| Research design | Mixed: image type (real / GAN / diffusion) **within**-subject × generation (Gen X / Millennial / Gen Z) **between**-subject (quasi-experimental) |
| Primary DV | Accuracy — analyzed with signal detection theory (d′ sensitivity + criterion bias) |
| Secondary DV | Response time (image onset → button tap) |
| Session duration | ~7–8 min typical, hard ceiling target 12–15 min |
| Stack | jsPsych frontend + PHP backend + MySQL (existing draft to be integrated) |
| Language | Thai and English (language select on landing page) |

## 2. Experiment Flow

```
QR code → Landing page (TH/EN language select)
   ↓
[1] Game intro — detective briefing ("people database contaminated with AI fakes")
   ↓
[2] Demographics form (~30s)
     birth year (required), gender; device/browser auto-detected
     (familiarity questions moved to game end — see [7]; no pre-game priming)
   ↓
[3] Instructions + 2–3 practice trials (non-test images, no feedback)
   ↓
[4] ROUND 1 — 2AFC: two faces side-by-side, "which one is AI?"
    12 trials, same-gender pairs (each trial = 1 AI + 1 real image → 24 images)
   ↓
[5] ROUND 2 — Single face: "Is this AI?" binary yes/no
    24 trials (12 AI + 12 real; AI = 6 GAN + 6 diffusion)
    Session totals: 24 AI + 24 real, equal
   ↓
[6] End screen: final score shown as "database cleaned %" (accuracy only) + leaderboard alias
   ↓
[7] Post-game data-use request → familiarity survey (5 items) → debrief
     [QUIT during any round: confirm → consent question → short debrief;
      saved trials kept, session marked incomplete, no survey on quit path]
   ↓
Data saved trial-by-trial to PHP/MySQL during play
```

## 3. Locked Decisions

| Decision | Choice |
|---|---|
| Consent timing | Post-game data-use request (⚠ verify IRB approval covers retroactive consent — see §9) |
| Level gating | None — everyone plays both rounds; "pass threshold" removed, rounds are Round 1 / Round 2 |
| Round 2 responses | Binary yes/no (no "maybe") |
| Leaderboard score | Accuracy only (no speed bonus — keeps RT data clean) |
| Per-trial feedback | None during play; final score shown only at end |
| Response deadline | No timeout |
| Confidence rating | Not included |
| Practice | Yes, 2–3 trials with non-test images |
| Trial counts | Round 1: 12 × 2AFC (24 images) · Round 2: 24 single (12 AI + 12 real) — session totals 24 AI (12 GAN + 12 diffusion) + 24 real, equal; six-cell design (3 sources × 2 genders) |
| 2AFC pairing | Same gender within every pair (removes gender as detection cue; age/ethnicity matching optional if tagged) |
| Image pool | Curated 3,816 images at 636/cell from 420K dataset, 6-cell balanced, ~80–150KB each, hosted on F1; 30-min rolling window prevents overlap between near-simultaneous players |
| Familiarity timing | 5-item digital/AI survey AFTER consent at game end (no pre-game priming); shown regardless of consent answer; all items required (NULL only on abandonment) |
| Quit option | Persistent quit control during rounds: confirm → consent → short debrief; saved trials kept, session marked incomplete; consented quitters' data usable |
| GAN stimulus mix | StyleGAN2 = equal ψ=0.5 / ψ=1 mix within every GAN cell (documented sub-factor) |
| Gender labels | Automated classifier on ~2.5K sampled candidates per source; low-confidence dropped; same instrument for all sources |
| Device | Personal phones via QR; device type recorded as covariate |
| Game theme | Detective narrative (story flavor only): briefing, "Investigation" round labels, Top Detectives leaderboard, score as "database cleaned %"; mechanics unchanged; debrief discloses the framing |

## 4. Stimulus Set

| Item | Status |
|---|---|
| Real faces | PreSocial_Real_FFHQ — 70,000 images (matches official FFHQ count); verify PreSocial license |
| AI faces — GAN | PreSocial_Fake_StyleGAN2 — 40K (20K ψ=0.5 + 20K ψ=1); equal mix per GAN cell |
| AI faces — diffusion | PreSocial_Fake_StableDiffusion1.5 — faces category, 10K images |
| Balance | Six-cell factorial: 3 sources (real/GAN/diffusion) × 2 genders, equal counts; age/ethnicity matched as background (verify) |
| Preprocessing | Identical crop, resolution, compression for ALL images, ~80–150KB each (removes quality-cue confound) |
| Pool | 420K full dataset → local pipeline (hash dedup, QA screens, processing) → 2–5K balanced deployment subset |
| Practice images | Separate set, never reused in main rounds |

## 5. Data Schema

**Session record** (created at session start, anonymous):
- `session_id` (random), `timestamp_start`, birth_year, generation_cohort (derived), gender, device/browser/screen (auto), language (TH/EN), familiarity_1..5 (nullable, set post-game), `consent_research` (bool, set post-game or on quit), `completed` (bool)

**Trial record** (one row per trial, saved immediately via AJAX):
- `session_id`, `round` (practice/1/2), `trial_index`, `image_id`, `image_type` (real/GAN/diffusion), `response`, `correct`, `RT_ms`, `timestamp`

## 6. Technical Architecture

- **Frontend**: jsPsych — preload plugin before Round 1, randomized image order per session, mobile-first two-button UI, TH/EN strings
- **Backend**: PHP save endpoint — one row per trial, idempotent, duplicate-submit throttling; separate prize-contact capture that never joins research data
- **Database**: MySQL, session + trial tables as §5
- **Hosting**: Azure App Service F1 (PHP + static; `*.azurewebsites.net` HTTPS included) + Azure Database for MySQL Flexible Server free tier (two separately credentialed DBs); F1 limits: 60 CPU-min/day, no Always On → 5-min keep-warm/monitor pings on /health.php
- **Images**: 2–5K curated pool served from App Service (~600MB, within 1GB disk), ~80–150KB each, identical processing; per-session sampling with 30-min no-reuse window (no client-side global manifest)

## 7. Analysis Plan

1. Per participant: d′ + criterion (signal detection), mean RT per condition
2. Mixed-effects models: accuracy ~ image type × generation + device covariate; same for RT
3. Age as continuous covariate fallback (Gen X underrepresentation risk at openhouse)
4. Careless-session filter rule defined before data collection
5. Scope claim: conclusions limited to face detection, not AI image detection generally
