## Selection funnel (all 120,000 → 4,444 deployed)

| Stage | Rule | Kept | Dropped |
|---|---|---|---|
| Sampling | Random (seed 20261031), all 120,000 eventually sampled across pipeline runs | 120,000 | — |
| Gender labeling | YuNet face detection (≥0.60) + Levi-Hassner gender net, confidence ≥0.70 | 99,725 | low-confidence / no face |
| Processing | Center-crop → 768×768 LANCZOS → JPEG quality-search to 80–150KB; pHash dedup; corrupt filter | 99,725 (0 dup, 0 corrupt, 100% in size band) | — |
| QA v3 framing | Exactly ONE face (YuNet ≥0.60); face box 25–90% of frame; face center ≤15% of frame center; **not monochrome** (mean HSV saturation ≥25); **not strongly turned** (eye-nose asymmetry ≤0.65 ≈ ±20° yaw, eye-line roll ≤15° — slight turn OK) | 88,915 | multi-face 4,501 · unreadable* 5,697 · turned 348 · off-center 91 · monochrome 76 · too-small 73 · rolled 21 · no-face 3 |
| Pool selection | Per-source × gender cell targets (see below); GAN cells 50/50 ψ mix; +2 practice per cell | **4,432 pool + 12 practice = 4,444** | remainder stays as spare on the build machine |

\* unreadable = files already deleted in an earlier cleanup pass; verdicts preserved.

sd15-Female (596) is capped by supply: the entire SD1.5 faces category is
exhausted and QA pass-rate for SD is low (~24%) — SD images are naturally
wider shots with smaller faces.

## Reuse policy (how players get images)

- Sessions draw **preferring never-used images** per cell → at 150–220
  players/day, roughly the first half-day sees all-new faces
- When a cell's fresh supply runs out → silent fallback to the **30-minute
  no-reuse window** (near-simultaneous players never share images; the pool
  can never exhaust mid-event)

## Known caveats (for the methods section)

- Gender labels are automated (one instrument across all sources); the 2015-era
  classifier's softmax skews Male on ambiguous faces
- sd15 cell sizes are supply-limited (see above); pool design compensates with
  equal per-session allocation
- Processing is identical across all three sources (no quality cue differs by source)
